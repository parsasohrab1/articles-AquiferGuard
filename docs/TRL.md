# Technology readiness (evidence-based)

**Level: TRL 4 on synthetic wells.** TRL 5 is not claimed.

## Evidence
7 unit tests pass. `research/run_study.py` (train 40 wells, calibrate 20 wells, test 40 wells; 6-month horizon; 300 months):

| Test setting | Coverage (target 0.90) | Forecast MAE (m) | Persistence MAE (m) |
|---|---|---|---|
| Same regime | 0.918 | 0.129 | 0.268 |
| Abstraction x1.5 from month 200 | 0.848 | 0.152 | 0.356 |

Alerts for "head below initial head minus 3 m within six months":

| Setting | Alert rule | Precision | Recall |
|---|---|---|---|
| Same regime | Conformal lower bound | 0.85 | 1.00 |
| Same regime | Point forecast | 0.96 | 0.98 |
| Same regime | Linear trend | 0.91 | 0.93 |
| Abstraction x1.5 | Conformal lower bound | 0.95 | 1.00 |
| Abstraction x1.5 | Point forecast | 0.99 | 0.98 |
| Abstraction x1.5 | Linear trend | 0.97 | 0.97 |

The conformal alert never misses an event in the same regime (recall 1.00) but raises more false alarms than the point forecast; a plain linear trend is a strong baseline. Coverage drops after the regime break.

## Not shown
Synthetic wells generated by a model of the same linear form the forecaster fits. No monitoring-well data, no InSAR.

## Next steps toward TRL 5
Monitoring-well series for one plain (for example from the water authority or a public groundwater archive), InSAR displacement for the same area, and validation on held-out wells and years.
